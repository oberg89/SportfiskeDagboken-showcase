# Backend showcase

The backend sample focuses on a session lifecycle rather than a production-complete API. It includes Jakarta Validation, controller-to-service delegation, a transactional application service, repository boundary, explicit state transition, DTO response, centralized error handling, and a mocked unit test.

The generic owner identifier demonstrates ownership boundaries only. Authentication, authorization, account recovery, entitlement checks, and private-location logic are excluded.

`V1__create_fishing_sessions.sql` is a showcase migration, not the private production schema.
